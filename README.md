# SenioreM

Голосовой помощник для Windows. Скажите «Сеньор, громкость десять» — громкость станет 10 %,
и он скажет вслух, что сделал.

## Для пользователя

1. Скачайте **SenioreM-Setup.exe** (≈ 30 МБ) со страницы Releases.
2. Запустите его. Права администратора и Python не нужны.
3. На рабочем столе появится ярлык **SenioreM**.

При запуске сначала открывается окно загрузки с названием и возможностями программы.
При самом первом запуске оно один раз докачивает русскую речевую модель (около 45 МБ),
потом программа открывается на весь экран: регистрация с кодом на почту или вход.

## Команды

| Что сказать | Что произойдёт |
|---|---|
| громкость десять / громкость на максимум | точная громкость |
| громче / тише / громче на двадцать | громкость ±10 или на сколько скажете |
| выключи звук / включи звук | звук |
| яркость семьдесят / ярче / темнее | яркость (на ноутбуках) |
| открой браузер / блокнот / калькулятор / проводник / загрузки / параметры / ютуб | открыть |
| найди погоду в Москве | поиск в интернете |
| пауза / следующий трек / предыдущий трек | музыка и видео |
| который час / какое сегодня число | время и дата |
| сделай скриншот | снимок экрана |
| сверни / разверни | окно (в свёрнутом виде продолжает слушать) |
| заблокируй компьютер | экран блокировки |
| стоп / что ты умеешь / закройся | — |

Можно сказать «Сеньор», дождаться сигнала и назвать команду. Команду можно и написать внизу экрана.

## Как собирается установщик (для автора)

Установщик собирает GitHub автоматически, на своём Windows-сервере, — у вас ничего ставить не нужно.

1. Загрузите эти файлы в репозиторий на GitHub.
2. **Settings → Secrets and variables → Actions → New repository secret** — добавьте почту,
   с которой будут уходить коды:
   - `SMTP_USER` — адрес (Gmail, Яндекс или Mail.ru);
   - `SMTP_PASSWORD` — **пароль приложения** этой почты (не обычный пароль):
     Gmail — myaccount.google.com/apppasswords (нужна двухэтапная проверка);
     Яндекс — id.yandex.ru → Безопасность → Пароли приложений;
     Mail.ru — Настройки → Безопасность → Пароли для внешних приложений.
   - при необходимости `SMTP_HOST` и `SMTP_PORT` (для других почтовых сервисов).

   Без секретов программа соберётся в тестовом режиме: код показывается прямо в окне.
3. Создайте тег `v1.0.0` (или **Actions → Сборка SenioreM → Run workflow**).
   Через ~5 минут `SenioreM-Setup.exe` появится в **Releases** (или в артефактах сборки).

Пароль почты-отправителя вшивается в программу. Его можно вытащить из `.exe`, поэтому
заведите для этого **отдельный ящик**, а не личный. Если программу будут скачивать
посторонние люди, надёжнее отправлять коды через маленький сервер — тогда пароль в программе не нужен.

## Данные

- Аккаунты — на этом компьютере: `%APPDATA%\SenioreM` (пароли хранятся в виде хэша).
- Речевая модель — `%LOCALAPPDATA%\SenioreM\model`.
- Журнал ошибок — `%APPDATA%\SenioreM\error.log`.
- Удаление — «Параметры → Приложения → SenioreM → Удалить».

<p align="center"><a href="https://github.com/v1lonck/SenioreM/releases/latest/download/SenioreM-Setup.exe"><b>⬇ Скачать SenioreM для Windows</b></a></p>

Голосовой помощник для Windows. Скажите «Сеньор, громкость десять» — громкость станет 10 %,
и он скажет вслух, что сделал.

## Для пользователя

1. Скачайте **[SenioreM-Setup.exe](https://github.com/v1lonck/SenioreM/releases/latest/download/SenioreM-Setup.exe)** (≈ 30 МБ).
2. Запустите его. Права администратора и Python не нужны.
3. На рабочем столе появится ярлык **SenioreM**.

При запуске сначала открывается окно загрузки с названием и возможностями программы.
При самом первом запуске оно один раз докачивает русскую речевую модель (около 45 МБ),
потом программа открывается на весь экран: регистрация с кодом на почту или вход.

## Что умеет

- **Голосовые команды на русском** — работает без интернета, понимает разговорные слова и сокращения.
- **ИИ-собеседник** — отвечает на вопросы и рассказывает, знает погоду, курс валют и новости.
- **Программы и игры** — открывает, сворачивает и закрывает; находит игру в лаунчере и нажимает «Играть».
- **Сценарии** — свои фразы: «игровой режим» запускает Steam, обход блокировок, VPN и т. д.
- **Таймеры и будильник** — красивые плашки с кнопками «Стоп» и «Ещё 5 минут».
- **YouTube и вкладки браузера** — «включи первое видео», «закрой первые пять вкладок».
- **Компаньон** — персонаж над панелью задач: Аля, Аки, Мия, Рэй, котёнок, лисёнок или свой из архива.
  Стоит, сидит или лежит — или меняет позу сам.
- **Оформление** — готовые темы, анимированные космические фоны, свой фон (картинка или GIF), стили круга.
- **Аккаунт** — аватар (много готовых или своя картинка), смена логина и пароля.

## Профиль

Нажмите на аватар справа вверху: оформление, сценарии и VPN, город, имя и голос помощника,
слова-обращения, история, программы и игры, ИИ, компаньон, запуск с Windows, аккаунт.

## Обновления

SenioreM сам проверяет обновления при запуске и каждые 30 минут. Новая версия скачивается
в фоне, а в углу экрана появляется кнопка **«Обновить»** — одно нажатие, и через пару секунд
программа снова открыта, уже обновлённая.

## Как собирается установщик (для автора)

Установщик собирает GitHub автоматически, на своём Windows-сервере, — у вас ничего ставить не нужно.

1. Загрузите эти файлы в репозиторий на GitHub.
2. **Settings → Secrets and variables → Actions → New repository secret** — добавьте почту,
   с которой будут уходить коды:
   - `SMTP_USER` — адрес (Gmail, Яндекс или Mail.ru);
   - `SMTP_PASSWORD` — **пароль приложения** этой почты (не обычный пароль):
     Gmail — myaccount.google.com/apppasswords (нужна двухэтапная проверка);
     Яндекс — id.yandex.ru → Безопасность → Пароли приложений;
     Mail.ru — Настройки → Безопасность → Пароли для внешних приложений.
   - при необходимости `SMTP_HOST` и `SMTP_PORT` (для других почтовых сервисов).

   Без секретов программа соберётся в тестовом режиме: код показывается прямо в окне.
3. Сборка запускается сама при каждой загрузке кода в ветку main
   (или вручную: **Actions → Сборка SenioreM → Run workflow**). Через ~5 минут `SenioreM-Setup.exe` появится в **Releases** (или в артефактах сборки).

Пароль почты-отправителя вшивается в программу. Его можно вытащить из `.exe`, поэтому
заведите для этого **отдельный ящик**, а не личный. Если программу будут скачивать
посторонние люди, надёжнее отправлять коды через маленький сервер — тогда пароль в программе не нужен.

## Данные

- Аккаунты — на этом компьютере: `%APPDATA%\SenioreM` (пароли хранятся в виде хэша).
- Речевая модель — `%LOCALAPPDATA%\SenioreM\model`.
- Журнал ошибок — `%APPDATA%\SenioreM\error.log`.
- Удаление — «Параметры → Приложения → SenioreM → Удалить».
